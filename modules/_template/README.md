# Módulo template

Copiá esta carpeta a `modules/<name>/`, renombrá archivos y editá `module.json`.

## Checklist

- [ ] `name` único y carpeta coincidente
- [ ] `provides` = funciones exportadas
- [ ] README con comandos, keys y par CLI↔IDE
- [ ] `config.psd1` con defaults
- [ ] Tests Pester (recomendado)

Ver [docs/module-contract.md](../../docs/module-contract.md).
