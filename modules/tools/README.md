# tools

Detecta CLIs útiles. **No instala paquetes solo** (consentimiento explícito fuera de este módulo).

## Comandos

| Comando | Descripción |
|---------|-------------|
| `Get-DsTool` | Lista catálogo + disponibilidad |
| `Test-DsTool git` | bool |
| `Use-DsTool fzf` | path o warning |
| `Register-DsTool` | agrega al catálogo |
| `Invoke-DsYazi` / `dsyazi` | TUI files (si instalado) |
| `Invoke-DsLazygit` / `dslazy` | TUI git |
| `Invoke-DsBtop` / `dsbtop` | monitor |
| `Invoke-DsNvim` / `dsnvim` | Neovim |
| `Invoke-DsZellij` / `dszj` | multiplexer |
| `Invoke-DsOha` / `dsoha` | HTTP load |
| `Invoke-DsBandwhich` / `dsnet` | network TUI |
| `Invoke-DsTuistore` / `dsstore` | TUI app store |

Catálogo incluye: git, fzf, rg, fd, bat, eza, zoxide, yazi, spf, lazygit, lazydocker, gdu, btop, nvim, delta, glow, gum, lnav, zellij, oha, bandwhich, tuistore, fastfetch, pwsh.

Suite estética documentada en hub Lennerk (`docs/aesthetic-tui.md`). **No instala** paquetes solo.
