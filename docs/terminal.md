# Windows Terminal (opcional)

DevShell no modifica WT automáticamente. Para alinear:

| Setting | Valor |
|---------|-------|
| background | `#0A0A0A` |
| foreground | `#FFFFFF` |
| accent / cursor | `#00C853` |
| font | Cascadia Code / JetBrains Mono |

Perfil que lance `pwsh` (no Windows PowerShell 5.1).
